🔧 Troubleshooting Steps

  1. Refresh the Page
    The most common solution is to refresh the browser page (F5 or Ctrl+R). The new panel should appear after a refresh.
  2. Check Browser Console
    Open browser developer tools (F12) and check the Console tab for any JavaScript errors. Look for errors related to "transform" or "meshes" icons.
  3. Verify Panel Tabs
    Look carefully at the top of the right sidebar. You should see small icon buttons arranged vertically. The Mesh Transform tab should have a "meshes" icon.
  4. Check CSS Loading
    Make sure all CSS files are loading properly. The panel tabs use .ov_panel_set_menu_button class for styling.
  5. Rebuild if Necessary
    If you're using a build system, you may need to rebuild the project to include the new files.

🎯 How to Access Mesh Transform

Once the tab is visible, follow these steps:

  1. Select a Mesh: In the left sidebar (Meshes panel), click on any mesh item (Brick, Concrete element, or Block)
  2. Click Mesh Transform Tab: In the right sidebar, click on the "Mesh Transform" tab (should have a meshes icon)
  3. Use Controls: You should now see position, rotation, and scale controls for the selected mesh
